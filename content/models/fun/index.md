# 6. 常見問題解答
faq:
  - question: "eReady Fun 是哪家車廠出的？是白牌還是綠牌？"
    answer: "由台鈴機車（SUZUKI 台灣總代理）推出，法規上屬於白牌（普通重型）機車。<br>
      eReady Fun 雖然是雙電池機車，但動力調校溫和，且車身高度友善。騎乘者必須持有普通重型機車駕照以上才能合法上路，並需懸掛普通白底機車牌。"
  - question: "eReady Fun 是充電還是換電？可以用 Gogoro 的換電站嗎？"
    answer: "採用換電系統，完全兼容 Gogoro 換電站。<br>
      eReady Fun 是 PBGN 換電聯盟的一員。全台超過 2,400 座 GoStation 換電站皆可 24 小時自由更換電池，不需要在家充電。電池資費方案則直接向 Gogoro Network 申辦與繳費。"
  - question: "eReady Fun 的車身規格如何？對小隻女友善嗎？"
    answer: "極其友善，被譽為「最貼心女生的白牌電車」之一。<br>
      台鈴機車融入了日系重車的造車工藝，特別針對台灣人的身形優化車體配重與幾何設計：<br>
      ．744mm 超低座高： 即使是 155 公分左右的嬌小騎士，也能輕鬆雙腳著地，停等紅燈時安心感十足。<br>
      ．省力駐車架： 中柱結構經過力學優化，牽車、立中柱時非常輕巧，力氣小的女生也能一踩即立。<br>
      ．動力輸出： 搭載 G2.2L 鋁合金水冷馬達，最大功率為 6.0kW（約 8.05 匹馬力），起步平順、不暴衝。<br>
      ．一鍵倒車： 標配電子倒車鍵，在市區狹窄車位中，按住即可自動後退，移車毫不費力。"
  - question: "eReady Fun 的置物與機能空間實用嗎？"
    answer: "日常生活的機能配備十分齊全：<br>
      ．26.5 公升大容量車廂： 內部空間平整，能輕鬆放入一頂 3/4 罩安全帽，再塞入雨衣或隨身包包。<br>
      ．內嵌式雙前置物空間： 前方兩側都有開放式大深槽，可以同時穩穩塞下手機與大瓶手搖飲（改善了許多電車前放不下飲料的缺點）。<br>
      ．前置 USB 充電座： 貼心標配，方便騎士邊導航邊幫手機補充電力。"
  - question: "eReady Fun 的避震好嗎？"
    answer: "舒適度高。<br>
      ．操控性與組裝扎實度極佳： 受益於台鈴機車（SUZUKI）數十年的燃油車調校經驗，車主普遍稱讚車架結構非常剛強，轉彎時「簧下重量」減輕有感，沒有早期某些電動車的塑膠感與異音。<br>
      ．避震與椅墊舒適度高： 標配雙槍式 5 段可調後避震，搭配加長型厚實泡棉座墊，長途通勤吸震效果非常好。"
